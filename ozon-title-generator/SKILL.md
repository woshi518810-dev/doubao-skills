# Ozon批量俄文标题/简介/标签生成（本地图片识别）

## 概述

遍历用户指定根目录下的每个一级子文件夹（每个子文件夹=1个SKU），取各文件夹内文件名排序第一的商品图片进行视觉识别，生成符合Ozon平台规范的**俄语商品标题、商品简介、10个主题标签**，三项内容合并写入对应SKU文件夹内的**一个** `ozon_listing.txt` 文件，并在对话中输出汇总表格。

**核心质量铁律**：标题必须让俄罗斯买家一眼看懂"这是什么商品"，禁止无意义文本堆砌、禁止语法错误、禁止文本前后不一致。每个标题生成后必须执行四轮强制校验（命名清晰度 → 文本一致性 → 无意义文本过滤 → 俄语语法），未通过则重写，直至全部通过。

**双模式说明**：
- **生成模式**：从图片识别开始，全新生成标题、简介、标签（执行流程第一步至第四步）。
- **语法优化模式**：用户提供已有标题，仅做合规语法修复（名词变格、形容词词尾、标点断句、俄语电商语法规范），不删减任何原始产品要素，规避敏感表述，输出完整标题文本无解释（详见"四、标题合规语法优化"）。

## 执行流程

### 第一步：扫描目录结构

运行辅助脚本获取所有SKU及其第一张图片路径：

```bash
python "<skill_dir>/scripts/scan_sku.py" "<用户输入的根目录绝对路径>"
```

脚本输出JSON数组，每项包含：
- `folder`：SKU文件夹绝对路径
- `folder_name`：SKU文件夹名
- `image`：第一张图片绝对路径（无图片时为null）
- `image_name`：第一张图片文件名（无图片时为null）

### 第二步：逐SKU视觉识别与内容生成

对脚本返回的每个有图片的SKU：

1. 用 `Read` 工具读取图片（`thumbnail_size` 设为 `large` 以看清细节）。
2. 仅提取图片**肉眼可见**的信息：商品品类、版型、外观细节、颜色、适用人群、风格、趋势主题。
3. **严禁编造**图片不存在的面料、参数、品牌、材质成分。
4. 按下方规则依次生成：俄语标题 → 俄语简介 → 10个俄语主题标签。
5. **标题生成后必须依次执行四轮强制校验**（见下方"标题质量强制校验流程"），任一环节不通过则重写标题，直至全部通过。
6. 对简介和标签执行合规自检（见下方）。

### 第三步：写入文件

对每个SKU，在其文件夹内创建/覆盖 **一个** `ozon_listing.txt` 文件，将标题、简介、标签三项内容合并写入，格式如下：

```
[TITLE]
{俄文标题}

[DESCRIPTION]
{俄文商品简介}

[TAGS]
{10个主题标签，空格分隔}
```

规则：
- 三个区块用 `[TITLE]`、`[DESCRIPTION]`、`[TAGS]` 标签明确分隔
- 标签行独占一行，标签之间用空格分隔
- 简介为一段连续文本
- 文件编码使用 UTF-8
- 无图片的SKU跳过，不生成txt

### 第四步：输出汇总表

对话中输出Markdown表格，列：SKU文件夹名 | 图片文件名 | 标题 | 简介 | 标签 | 合规状态。
- 合规通过：标注 `通过`
- 合规不通过：标注具体问题（如 `标题核心商品名缺失`、`文本一致性失败：颜色词性数不一致`、`含无意义热词堆砌`、`语法错误：变格不正确` 等），内容仍写入txt
- 无图片：标注 `无有效图片，跳过`

## 一、标题生成规则

### 结构
`[核心商品名] + [版型/款式] + [外观特征] + [适用对象] + [合规热销风格词]`

**核心商品名必须置于标题最开头**，且必须是俄罗斯电商通用的标准品类词，确保买家扫一眼第一个词就知道是什么商品。

### 核心商品名命名规范（买家一眼看懂）

**目的**：让俄罗斯买家在搜索结果列表中，仅凭标题前几个词就能准确判断商品品类，不产生歧义。

**强制规则**：
1. **首词必须是标准品类名词**（单数主格），禁止用模糊词、风格词、热词开篇。
2. **品类词必须精准对应图片实物**，禁止上义词替代下义词：
   - 衬衫必须写 `рубашка`，禁止笼统写 `одежда`/`топ`/`блузка`（除非确实是女式短衫）
   - 连衣裙必须写 `платье`，禁止写 `юбка`/`костюм`
   - T恤必须写 `футболка`，禁止写 `рубашка`/`топ`
   - 卫衣必须写 `свитшот` 或 `худи`（有帽写худи，无帽写свитшот），禁止混写
   - 裤子必须区分 `брюки`（西裤/休闲裤）、`джинсы`（牛仔裤）、`легинсы`（打底裤）、`шорты`（短裤）
   - 外套必须区分 `куртка`（夹克）、`пальто`（大衣）、`ветровка`（风衣）、`пуховик`（羽绒服）
3. **适用人群紧跟品类词**，使用正确形式：
   - 男士：`мужская`（阴性名词后）/ `мужской`（阳性名词后）/ `мужские`（复数名词后）
   - 女士：`женская` / `женский` / `женские`
   - 儿童：`детская` / `детский` / `детские`
   - 通用：`унисекс`
4. **禁止自创品类词或中式直译**，例如：
   - 禁止 `верхняя одежда` 作为首词（过于宽泛，买家无法判断具体品类）
   - 禁止 `одежда для дома` 作为首词（应写具体品类如 `халат`/`пижама`）
   - 禁止把"套装"笼统写 `комплект`，应写 `костюм` 或具体两件套描述
5. **标题前3个词必须构成完整的商品识别信息**：`[品类] + [适用人群] + [核心款式/版型]`，例如 `Рубашка мужская длинный рукав`、`Платье женское летнее`。

### 文本一致性强制检查

**目的**：确保标题中所有修饰词与被修饰名词在性、数、格上完全一致，同一概念前后不矛盾、不重复。

**逐项检查清单**：

1. **形容词与名词性数一致**：
   - `рубашка`（阴）→ `мужская рубашка`、`синяя рубашка`、`стильная рубашка`
   - `футболка`（阴）→ `женская футболка`、`белая футболка`
   - `свитшот`（阳）→ `мужской свитшот`、`серый свитшот`
   - `платье`（中）→ `летнее платье`、`черное платье`
   - `брюки`（复）→ `мужские брюки`、`черные брюки`
   - **发现不一致立即修正**，例如 `мужской рубашка` 必须改为 `мужская рубашка`。

2. **颜色词与名词一致**：
   - 同一件商品只有一个主色时，颜色词只出现一次且形式正确
   - 多色/拼色用 `в клетку`、`в полоску`、`принт`、`цветной` 等表述，禁止同时写两个矛盾颜色词
   - 禁止 `синяя рубашка синий` 这类重复且不一致的错误

3. **版型/风格前后不矛盾**：
   - 禁止同时出现 `свободный крой`（宽松）和 `облегающий`（修身）
   - 禁止同时出现 `оверсайз` 和 `приталенный`
   - 禁止同时出现 `спортивный` 和 `деловой`（除非确实是商务休闲款，用 `кэжуал` 统一）
   - 图片中是什么版型就只写对应词，不做风格叠加

4. **同一概念不重复表达**：
   - 禁止 `рубашка рубашечная`、`футболка для футбола` 这类同义反复
   - 禁止 `модный стильный` 两个近义热词连用（热词本身最多2-3个且不重复语义）
   - 禁止 `длинный рукав с длинным рукавом` 重复描述袖长

5. **名词变格在标题中统一**：
   - 标题中品类名词保持主格（именительный падеж）
   - 修饰短语中的名词按俄语语法正确变格，例如 `воротник на пуговицах`（六格复数）、`карман на груди`（六格）
   - 禁止同一短语内变格错误，例如 `воротник на пуговица` 必须改为 `воротник на пуговицах`

6. **单复数一致**：
   - `брюки`、`джинсы`、`шорты`、`легинсы` 永远用复数，修饰词也用复数
   - `рубашка`、`платье`、`футболка`、`свитшот` 用单数，修饰词也用单数
   - 禁止 `мужская брюки` 这类单复数不一致错误

### 无意义文本过滤规则

**目的**：清除标题中对买家理解商品没有任何信息增量的词汇、堆砌和中式俄语表达。

**必须删除或重写的情况**：

1. **纯热词堆砌**：
   - 禁止 `стильный модный современный удобный универсальный практичный` 连续3个以上热词
   - 热词最多2-3个，且每个热词必须与商品实际特征相关（例如家居服可以用 `удобный`，正装衬衫不宜用 `спортивный`）
   - 删除后不影响商品理解的热词一律删除

2. **无信息增量的形容词**：
   - 禁止 `хороший`、`отличный`、`замечательный`、`прекрасный`、`классный` 这类主观评价词
   - 禁止 `новый`（除非确实是新品且图片有新品标识，Ozon标题通常不需要）
   - 禁止 `обычный`、`стандартный` 这类无意义描述

3. **中式俄语直译**：
   - 禁止逐字翻译中文电商用语，例如：
     - "百搭" → 禁止写 `все подходит`，应写 `универсальный` 或直接不写
     - "显瘦" → 禁止写 `стройнит`（中式表达），应写 `приталенный`/`облегающий` 或不写
     - "高端" → 禁止写 `высокий конец`，应写 `стильный`/`элегантный` 或不写
     - "气质" → 禁止写 `темперамент`，应写 `элегантный` 或不写
   - 不确定俄语是否地道时，优先用简单、确定正确的词，不追求"高级感"而牺牲准确性

4. **语义空洞的短语**：
   - 禁止 `для любого случая`、`на все времена`、`лучший выбор` 这类空洞表述
   - 禁止 `модный тренд 2026` 这类无依据的年份趋势词（除非图片明确是当季新款且有依据）
   - 禁止 `ограниченная серия`、`эксклюзив` 这类无依据的稀缺性表述

5. **重复信息**：
   - 同一特征（颜色、袖长、领型）只描述一次
   - 品类词只出现一次（标题开头），禁止后面再重复 `рубашка`
   - 删除任何可以被其他词完全覆盖的冗余词

### 语法错误强制校验

**目的**：确保标题俄语语法100%正确，符合俄罗斯本土电商用语习惯。

**逐项校验**：

1. **名词变格正确性**：
   - 标题主名词保持主格单数（或复数，如брюки）
   - 介词短语中的名词变格正确：`с` + 工具格、`в` + 六格/四格、`на` + 六格/四格、`для` + 二格
   - 常见正确搭配：`с длинным рукавом`（工具格）、`на пуговицах`（六格复数）、`на груди`（六格）、`для повседневной носки`（二格）

2. **形容词变格正确性**：
   - 形容词与被修饰名词性数格完全一致（见"文本一致性"部分）
   - 形容词短尾形式在标题中一般不用，优先用长尾形式
   - 颜色形容词：`синий`/`синяя`/`синее`/`синие`，`белый`/`белая`/`белое`/`белые` 等

3. **词性正确**：
   - 禁止把副词当形容词用，例如 `стильно рубашка` 必须改为 `стильная рубашка`
   - 禁止把名词当形容词用，例如 `спорт рубашка` 必须改为 `спортивная рубашка`
   - 禁止动词不定式直接修饰名词，例如 `гулять рубашка` 必须改为 `рубашка для прогулок` 或删除

4. **词序符合俄语习惯**：
   - 形容词一般放在名词前：`синяя рубашка`，不是 `рубашка синяя`（后者是口语强调，标题不用）
   - 品类词放最前，修饰词在后，符合Ozon电商标题习惯
   - 短语内部词序正确：`длинный рукав` 不是 `рукав длинный`

5. **拼写正确性**：
   - 检查元音交替：`платье`（不是 `платье`）、`юбка`（不是 `юбка` 正确）
   - 检查词尾：`мужская`（不是 `мужскаяя`）、`женская`（不是 `женскаяя`）
   - 检查连字符：`темно-синий`（有连字符）、`светло-серый`（有连字符）、`оверсайз`（无连字符）
   - 检查外来词拼写：`свитшот`（不是 `свитшот` 正确）、`худи`（不变格）、`легинсы`（复数）

6. **俄语电商用语习惯**：
   - 标题用名词短语堆砌，不用完整句子，不加句号
   - 不用第一人称、第二人称（`я`、`ты`、`вы`）
   - 不用感叹号、问号
   - 商品特征用客观描述，不用命令式（`купи`、`закажи`）

### 标题质量强制校验流程（每个标题必须执行）

生成标题初稿后，**必须按顺序执行以下四轮校验**，每轮不通过则修正后重新从该轮开始：

**第一轮：命名清晰度校验**
- [ ] 标题第一个词是标准品类名词（单数主格）？
- [ ] 品类词精准对应图片实物，没有用上义词替代？
- [ ] 前3个词构成 `[品类]+[人群]+[核心款式]` 的完整识别信息？
- [ ] 买家扫一眼前3个词就能准确判断是什么商品？
- 不通过 → 重写标题开头，确保品类词精准前置。

**第二轮：文本一致性校验**
- [ ] 所有形容词与被修饰名词性数格一致？
- [ ] 颜色词形式正确且不矛盾？
- [ ] 版型/风格词前后不矛盾？
- [ ] 没有同一概念重复表达？
- [ ] 名词变格在短语内正确？
- [ ] 单复数一致（брюки类永远复数）？
- 不通过 → 修正不一致处，重新检查。

**第三轮：无意义文本过滤**
- [ ] 热词不超过2-3个且无堆砌？
- [ ] 无主观评价词（хороший/отличный等）？
- [ ] 无中式俄语直译？
- [ ] 无语义空洞短语？
- [ ] 无重复信息？
- [ ] 删除任何词后是否影响商品理解？不影响则删除。
- 不通过 → 删除无意义词或重写对应部分。

**第四轮：语法强制校验**
- [ ] 名词变格全部正确？
- [ ] 形容词变格全部正确？
- [ ] 词性使用正确（无副词当形容词等）？
- [ ] 词序符合俄语电商习惯？
- [ ] 拼写全部正确（含连字符、外来词）？
- [ ] 符合俄语电商用语习惯（名词短语、无句子、无标点错误）？
- 不通过 → 修正语法错误，重新检查。

**四轮全部通过后**，再检查字符长度（60-180）和黑名单，最终确认标题可用。

### 常见错误反面示例（必须避免）

| 错误标题 | 问题 | 修正后 |
|---|---|---|
| `одежда мужская стильная модная современная` | 品类词过于宽泛（одежда），热词堆砌，买家不知道具体是什么 | `Рубашка мужская длинный рукав темно-синяя повседневная стильная` |
| `мужской рубашка синий длинный рукав` | 形容词性不一致（мужской→мужская, синий→синяя） | `Рубашка мужская синяя с длинным рукавом` |
| `рубашка для футбола спортивная модная` | 品类错误（T恤应写футболка），中式表达 | `Футболка мужская спортивная белая повседневная` |
| `стильная модная современная удобная универсальная рубашка` | 热词堆砌（5个），品类词后置 | `Рубашка мужская свободного кроя серая повседневная универсальная` |
| `брюки мужская черный классический прямой крой` | 单复数不一致（брюки是复数，应用мужские/черные/классические） | `Брюки мужские черные классические прямого кроя` |
| `платье женское для любого случая отличный выбор` | 语义空洞短语，主观评价 | `Платье женское летнее цветочное свободного кроя` |
| `свитшот мужской оверсайз облегающий` | 版型矛盾（оверсайз宽松 vs облегающий修身） | `Свитшот мужской оверсайз серый с круглым вырезом` |
| `куртка женская верхняя одежда теплая` | 重复（куртка已是上衣，无需верхняя одежда） | `Куртка женская осенняя черная свободного кроя` |

### 字符长度
60-180字符（Ozon平台推荐区间）。四轮校验通过后检查长度，过短则补充可见特征，过长则删除冗余修饰词（优先删热词，保留核心商品信息）。

### 允许使用的合规热词（每个标题最多2-3个，禁止堆砌）
стильный, удобный, универсальный, повседневный, практичный, современный, модный

热词使用原则：每个热词必须与商品实际特征相关，删除后不影响商品理解的热词一律删除。

### 黑名单（强制过滤，出现即删除或重写）
- 夸大词：лучший, супер, номер один, идеальный, топ 1, самый
- 侵权/违禁：оригинал, лицензия, любые бренды, IP-персонажи, защищенные авторским правом принты
- 促销用语：скидка, акция, распродажа, бесплатно
- 主观评价词：хороший, отличный, замечательный, прекрасный, классный
- 语义空洞短语：для любого случая, на все времена, лучший выбор, ограниченная серия, эксклюзив

### 符号约束
仅允许英文标点（逗号、句号、连字符、空格）。**禁止** `& * @ # « » № " '` 及其他特殊符号。标题末尾不加句号。

### 节日逻辑
仅当图片中**明确可见**节日装饰元素（如圣诞树、南瓜、爱心、烟花等）时，才添加对应节日词汇；无对应元素绝不添加。不可夸大。

### 语言要求
严格遵守俄语本土语法：名词变格正确、形容词与名词性数一致、搭配符合俄罗斯电商用语习惯，拒绝中式机翻俄语。生成后必须再检查一遍俄文语法及俄罗斯人用语习惯，定义准确。不确定是否地道时，优先用简单、确定正确的词，不追求"高级感"而牺牲准确性。

## 四、标题合规语法优化（仅修复语法，不改动产品要素）

### 适用场景
当用户提供已有俄文商品标题，要求仅做合规语法修复时使用本模式。本模式**不生成新标题、不删减信息、不做精简**，仅对原始标题执行语法合规修复后输出完整标题文本。

### 核心铁律（不可违反）
1. **不删减原始标题任何信息**：原始标题中的每一个产品要素（品类、版型、袖长、颜色、印花、场景、风格、适用人群等）必须全部保留，禁止删除任何词。
2. **不做精简**：不得以"优化"为由缩短标题，不得合并或省略任何原始描述。
3. **仅做合规语法修复**：修正范围严格限定为名词变格、形容词词尾、标点断句、俄语电商语法规范四类。
4. **不改动原有产品要素**：不得替换、改写、重新解释原始标题中的产品信息，仅修正其语法形式。
5. **输出完整标题文本，无额外解释**：仅输出修复后的完整标题，不输出校验记录、修改对比、说明文字。

### 修复范围（仅以下四类）

#### 1. 名词变格修正
- 标题主名词保持主格（именительный падеж）
- 介词短语中的名词按语法正确变格：
  - `с` + 工具格（творительный падеж）：`с длинным рукавом`（不是 `с длинный рукав`）
  - `в` + 四格（表穿戴/图案）：`в клетку`, `в полоску`；`в` + 六格（表位置）：`в гардеробе`
  - `на` + 六格：`на пуговицах`（六格复数）、`на груди`（六格）
  - `для` + 二格（родительный падеж）：`для повседневной носки`
  - `без` + 二格：`без рукава`
- 复数名词（брюки, джинсы, шорты, легинсы）保持复数形式，修饰词同步用复数
- 不变格名词（худи, пальто, кашне）保持原形
- 修正示例：
  - `воротник на пуговица` → `воротник на пуговицах`
  - `с длинный рукав` → `с длинным рукавом`
  - `для повседневный носка` → `для повседневной носки`
  - `прямой крой`（作修饰语时）→ `прямого кроя`（二格）

#### 2. 形容词词尾修正
- 形容词必须与被修饰名词在性、数、格上完全一致：
  - 阴性名词（рубашка, футболка, юбка, кофта）→ 形容词词尾 `-ая`/`-яя`：`мужская рубашка`, `синяя футболка`
  - 阳性名词（свитшот, костюм, пиджак, жилет）→ 形容词词尾 `-ый`/`-ий`/`-ой`：`мужской свитшот`, `серый костюм`
  - 中性名词（платье, пальто）→ 形容词词尾 `-ое`/`-ее`：`летнее платье`, `черное пальто`
  - 复数名词（брюки, джинсы, шорты, легинсы）→ 形容词词尾 `-ые`/`-ие`：`мужские брюки`, `черные джинсы`
- 颜色形容词同步修正：
  - `синий` → `синяя`（阴）/ `синее`（中）/ `синие`（复）
  - `белый` → `белая`/`белое`/`белые`
  - `черный` → `черная`/`черное`/`черные`
  - `красный` → `красная`/`красное`/`красные`
  - `зеленый` → `зеленая`/`зеленое`/`зеленые`
  - `серый` → `серая`/`серое`/`серые`
  - `бежевый` → `бежевая`/`бежевое`/`бежевые`
- 复合颜色词保留连字符：`темно-синий`, `светло-серый`, `ярко-красный`, `бело-черный`
- 适用人群形容词紧跟品类词，性数一致：`мужская рубашка`（不是 `мужской рубашка`）
- 修正示例：
  - `мужской рубашка` → `мужская рубашка`
  - `синий платье` → `синее платье`
  - `черный брюки` → `черные брюки`
  - `мужская свитшот` → `мужской свитшот`
  - `красный юбка` → `красная юбка`

#### 3. 标点合理断句
- 标题中各独立语义组之间用**英文逗号+空格**分隔，使语义分组清晰可读：
  - `Рубашка мужская, с длинным рукавом, в клетку, синяя, повседневная`
- 逗号用于分隔独立语义组（品类+人群 / 袖长 / 图案 / 颜色 / 风格），**不得在词组内部断句**
- 禁止使用俄文标点（«»、—、…），仅使用英文逗号、连字符、空格
- 标题末尾不加句号、不加感叹号、不加问号
- 禁止连续逗号、禁止逗号前后缺空格
- 品类词首字母大写，其余小写（专有名词除外）
- 修正示例：
  - `Рубашка мужская с длинным рукавом в клетку синяя повседневная` → `Рубашка мужская, с длинным рукавом, в клетку, синяя, повседневная`
  - `Рубашка,мужская,с длинным рукавом` → `Рубашка мужская, с длинным рукавом`
  - `рубашка Мужская, С Длинным Рукавом` → `Рубашка мужская, с длинным рукавом`

#### 4. 俄语电商语法规范
- 标题使用名词短语结构，不用完整句子、不用动词
- 品类名词置于标题最开头，保持主格
- 适用人群形容词紧跟品类词，性数一致
- 外来词拼写规范：`свитшот`, `худи`, `оверсайз`, `легинсы`, `кэжуал`, `лонгслив`, `блейзер`, `чиносы`
- 不变格名词（худи, пальто, кашне）保持原形，修饰词按约定性别变化（худи通常用阳性，пальто用中性）
- 禁止中式俄语表达（见"无意义文本过滤规则"中的中式俄语清单）
- 禁止把副词当形容词：`стильно рубашка` → `стильная рубашка`
- 禁止把名词当形容词：`спорт рубашка` → `спортивная рубашка`
- 禁止动词不定式直接修饰名词：`гулять рубашка` → `рубашка для прогулок`
- 序数词/尺寸词正确形式：`размер M`（不用 `размером M`），`3/4 рукав`（不变格）

### 敏感内容规避（必须执行）
在语法修复过程中，如发现原始标题包含以下敏感表述，必须在**不改变产品要素含义**的前提下做合规替换，**不得删除该产品要素**：

1. **宗教敏感**：
   - 禁止直接使用宗教符号/神祇名称作为商品描述词
   - 如原始标题含宗教相关图案描述（如 `крестик` 小十字架印花），保留图案客观描述但不得添加宗教评价或引申义
   - 禁止使用 `святой`, `божественный`, `райский`, `ангельский` 等宗教色彩强烈的修饰词

2. **暴力/武器敏感**：
   - 禁止使用具体武器名称作为风格词（如 `пистолет`, `нож`, `винтовка`, `граната`）
   - 如原始标题含迷彩/军事风格描述（如 `милитари`, `камуфляж`），保留客观风格描述但不得添加暴力引申
   - 禁止使用 `кровавый`, `убийственный`, `боевой`, `военный`（作修饰词时）等暴力色彩词
   - 武器名称印花 → 替换为 `в стиле милитари`（保留军事风格要素，去除具体武器名称）

3. **违禁图案敏感**：
   - 禁止使用纳粹符号、极端组织标志相关词汇（свастика, фашистский и т.д.）
   - 禁止使用毒品相关词汇（`марихуана`, `гашиш`, `наркотик`, `каннабис`）
   - 如原始标题含叶子/植物印花（如 `в листочек`, `растительный принт`），仅保留客观图案描述，不得关联违禁含义
   - 禁止使用色情/低俗表述

4. **替换原则**：
   - 敏感词替换为客观、中性的描述词，**不删除该产品要素**
   - 替换后必须确保原始产品要素（印花、风格）仍然存在且可识别
   - 替换仅针对敏感词本身，不波及周围正常描述

### 必须保留的原始产品要素清单
语法修复时，以下要素**必须全部保留**，不得遗漏、不得删减：
- [ ] 品类词（рубашка/платье/футболка/брюки/джинсы/свитшот/худи/куртка等）
- [ ] 适用人群（мужская/женская/детская/унисекс）
- [ ] 版型（свободный крой/облегающий/оверсайз/приталенный/прямой крой等）
- [ ] 袖长（длинный рукав/короткий рукав/без рукава/3/4 рукав/лангслив等）
- [ ] 颜色（所有颜色描述，包括复合色、渐变色、多色拼色）
- [ ] 印花/图案（в клетку/в полоску/цветочный принт/геометрический принт/абстрактный принт等）
- [ ] 领型（воротник на пуговицах/круглый вырез/V-образный вырез/стойка等）
- [ ] 细节（нагрудный карман/пуговицы/молния/пояс/капюшон等）
- [ ] 场景/风格（повседневная/деловая/спортивная/вечерняя/кэжуал/классическая等）
- [ ] 季节（летняя/зимняя/весенняя/осенняя/демисезонная）

### 输出格式
- **仅输出修复后的完整商品标题文本**，独占一行
- 不输出任何解释、说明、校验记录、修改对比、前后对照
- 标题末尾无句号、无感叹号、无问号
- 如原始标题无语法问题，原样输出（仅统一首字母大写和标点格式）

### 修复前后对比示例（仅供内部参考，不输出给用户）

**示例1：形容词词尾+名词变格+标点修复**
- 原始：`мужской рубашка синий с длинный рукав в клетку`
- 修复后：`Рубашка мужская, синяя, с длинным рукавом, в клетку`
- 修复点：мужской→мужская, синий→синяя, с длинный рукав→с длинным рукавом, 添加逗号断句, 品类词首字母大写

**示例2：单复数+二格+标点修复**
- 原始：`брюки мужская черный классический прямой крой`
- 修复后：`Брюки мужские, черные, классические, прямого кроя`
- 修复点：мужская→мужские, черный→черные, классический→классические, прямой крой→прямого кроя（二格）, 添加逗号断句

**示例3：敏感词合规替换+词尾修复**
- 原始：`футболка мужская с принтом пистолет черный спортивный`
- 修复后：`Футболка мужская, с принтом в стиле милитари, черная, спортивная`
- 修复点：пистолет→в стиле милитари（敏感词替换，保留军事风格印花要素）, черный→черная, спортивный→спортивная, 添加逗号断句

**示例4：中性名词+不变格名词+标点修复**
- 原始：`платье женский красный летний цветочный принт свободный крой`
- 修复后：`Платье женское, красное, летнее, с цветочным принтом, свободного кроя`
- 修复点：женский→женское, красный→красное, летний→летнее, цветочный принт→с цветочным принтом（工具格）, свободный крой→свободного кроя（二格）, 添加逗号断句

## 合规自检清单（每项内容必须逐项检查）

### 标题（必须四轮校验全部通过）
1. **命名清晰度**：首词是标准品类名词？品类精准对应图片？前3词可独立识别商品？
2. **文本一致性**：形容词与名词性数格一致？颜色/版型不矛盾？无重复概念？变格正确？单复数一致？
3. **无意义文本**：热词≤3且无堆砌？无主观评价词？无中式俄语？无空洞短语？无重复信息？
4. **语法正确**：名词变格正确？形容词变格正确？词性正确？词序符合习惯？拼写正确？符合电商用语？
5. 无侵权IP、品牌名、夸大违禁词汇、促销用语
6. 无禁止特殊符号，仅使用英文标点，末尾无句号
7. 字符长度在60-180之间
8. 所有特征均来自图片，无虚构信息
9. 节日词汇仅在图片有对应元素时出现
10. 热词不超过3个，无堆砌

### 简介
1. 俄语语法正确，符合俄罗斯人用语习惯（变格、性数一致、动词变位）
2. 2-4句话，80-300字符
3. 无夸大词、无促销用语、无品牌名
4. 所有描述基于图片可见特征，无虚构
5. 语气自然有吸引力
6. 无中式俄语直译

### 标签
1. 共10个，以`#`开头
2. 只含俄语字母和数字
3. 多词用下划线连接
4. 每个≤30字符（含`#`）
5. 空格分隔，一行
6. 无品牌、无参数、无产品名
7. 与图片风格/主题相关

### 标题合规语法优化（仅修复模式）
1. **未删减任何原始产品要素**：品类、人群、版型、袖长、颜色、印花、领型、细节、场景、季节全部保留
2. **未做精简**：标题长度未因"优化"而缩短，无信息丢失
3. **名词变格正确**：主名词主格、介词短语变格正确、复数名词保持复数
4. **形容词词尾正确**：所有形容词与被修饰名词性数格一致
5. **标点合理**：语义组间用英文逗号+空格分隔，无连续逗号，末尾无句号
6. **俄语电商语法规范**：名词短语结构、品类词前置、外来词拼写正确、无中式俄语
7. **敏感内容已规避**：宗教/暴力/违禁图案敏感词已做合规替换，且产品要素未丢失
8. **输出格式正确**：仅输出完整标题文本，无解释、无校验记录、无对比
9. **首字母大写**：品类词首字母大写，其余小写（专有名词除外）

## 注意事项

- 用户输入的路径可能包含空格或中文，脚本调用时路径用双引号包裹。
- 图片格式支持：jpg, jpeg, png, webp, bmp。
- 文件名排序采用自然排序（01.jpg 排在 2.jpg 之前）。
- 若根目录下没有子文件夹（即根目录本身就是SKU），则将根目录本身视为唯一SKU处理。
- 若图片中人物面部完整露出，不影响内容生成，仅关注服装/商品本身。
- 标签中的俄语字母使用西里尔字母，不使用拉丁字母转写。
- **标题质量是本技能的最高优先级**：宁可标题短一些、朴素一些，也不能出现语法错误、无意义文本或让买家看不懂的品类词。四轮校验必须严格执行，不通过则重写，不得妥协。
- 不确定俄语表达是否地道时，优先使用最简单、最确定正确的词汇，避免为了"高级感"而使用不确定的表达导致语法错误。
- **语法优化模式**：当用户要求"优化标题/修复语法/合规优化"时，进入"四、标题合规语法优化"模式，仅修复语法不改动产品要素，输出完整标题无解释。该模式下不执行四轮校验中的"无意义文本过滤"（因为不允许删减信息），仅执行语法修复和敏感词替换。
