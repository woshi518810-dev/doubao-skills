# Ozon批量俄文标题/简介/标签生成（本地图片识别）

## 概述

遍历用户指定根目录下的每个一级子文件夹（每个子文件夹=1个SKU），取各文件夹内文件名排序第一的商品图片进行视觉识别，生成符合Ozon平台规范的**俄语商品标题、商品简介、10个主题标签**，三项内容合并写入对应SKU文件夹内的**一个** `ozon_listing.txt` 文件，并在对话中输出汇总表格。

**核心质量铁律**：标题必须让俄罗斯买家一眼看懂"这是什么商品"，禁止无意义文本堆砌、禁止语法错误、禁止文本前后不一致。每个标题生成后必须执行四轮强制校验（命名清晰度 → 文本一致性 → 无意义文本过滤 → 俄语语法），未通过则重写，直至全部通过。

## 执行流程

### 第一步：扫描目录结构

运行辅助脚本获取所有SKU及其第一张图片路径：

```bash
python "<skill_dir>/scripts/scan_sku.py" "<用户输入的根目录绝对路径>"
```

脚本输出JSON数组，每项包含：
- `folder`：SKU文件夹绝对路径
- `folder_name`：SKU文件夹名
- `image`：第一张图片绝对路径（无图片时为null）
- `image_name`：第一张图片文件名（无图片时为null）

### 第二步：逐SKU视觉识别与内容生成

对脚本返回的每个有图片的SKU：

1. 用 `Read` 工具读取图片（`thumbnail_size` 设为 `large` 以看清细节）。
2. 仅提取图片**肉眼可见**的信息：商品品类、版型、外观细节、颜色、适用人群、风格、趋势主题。
3. **严禁编造**图片不存在的面料、参数、品牌、材质成分。
4. 按下方规则依次生成：俄语标题 → 俄语简介 → 10个俄语主题标签。
5. **标题生成后必须依次执行四轮强制校验**（见下方"标题质量强制校验流程"），任一环节不通过则重写标题，直至全部通过。
6. 对简介和标签执行合规自检（见下方）。

### 第三步：写入文件

对每个SKU，在其文件夹内创建/覆盖 **一个** `ozon_listing.txt` 文件，将标题、简介、标签三项内容合并写入，格式如下：

```
[TITLE]
{俄文标题}

[DESCRIPTION]
{俄文商品简介}

[TAGS]
{10个主题标签，空格分隔}
```

规则：
- 三个区块用 `[TITLE]`、`[DESCRIPTION]`、`[TAGS]` 标签明确分隔
- 标签行独占一行，标签之间用空格分隔
- 简介为一段连续文本
- 文件编码使用 UTF-8
- 无图片的SKU跳过，不生成txt

### 第四步：输出汇总表

对话中输出Markdown表格，列：SKU文件夹名 | 图片文件名 | 标题 | 简介 | 标签 | 合规状态。
- 合规通过：标注 `通过`
- 合规不通过：标注具体问题（如 `标题核心商品名缺失`、`文本一致性失败：颜色词性数不一致`、`含无意义热词堆砌`、`语法错误：变格不正确` 等），内容仍写入txt
- 无图片：标注 `无有效图片，跳过`

## 一、标题生成规则

### 结构
`[核心商品名] + [版型/款式] + [外观特征] + [适用对象] + [合规热销风格词]`

**核心商品名必须置于标题最开头**，且必须是俄罗斯电商通用的标准品类词，确保买家扫一眼第一个词就知道是什么商品。

### 核心商品名命名规范（买家一眼看懂）

**目的**：让俄罗斯买家在搜索结果列表中，仅凭标题前几个词就能准确判断商品品类，不产生歧义。

**强制规则**：
1. **首词必须是标准品类名词**（单数主格），禁止用模糊词、风格词、热词开篇。
2. **品类词必须精准对应图片实物**，禁止上义词替代下义词：
   - 衬衫必须写 `рубашка`，禁止笼统写 `одежда`/`топ`/`блузка`（除非确实是女式短衫）
   - 连衣裙必须写 `платье`，禁止写 `юбка`/`костюм`
   - T恤必须写 `футболка`，禁止写 `рубашка`/`топ`
   - 卫衣必须写 `свитшот` 或 `худи`（有帽写худи，无帽写свитшот），禁止混写
   - 裤子必须区分 `брюки`（西裤/休闲裤）、`джинсы`（牛仔裤）、`легинсы`（打底裤）、`шорты`（短裤）
   - 外套必须区分 `куртка`（夹克）、`пальто`（大衣）、`ветровка`（风衣）、`пуховик`（羽绒服）
3. **适用人群紧跟品类词**，使用正确形式：
   - 男士：`мужская`（阴性名词后）/ `мужской`（阳性名词后）/ `мужские`（复数名词后）
   - 女士：`женская` / `женский` / `женские`
   - 儿童：`детская` / `детский` / `детские`
   - 通用：`унисекс`
4. **禁止自创品类词或中式直译**，例如：
   - 禁止 `верхняя одежда` 作为首词（过于宽泛，买家无法判断具体品类）
   - 禁止 `одежда для дома` 作为首词（应写具体品类如 `халат`/`пижама`）
   - 禁止把"套装"笼统写 `комплект`，应写 `костюм` 或具体两件套描述
5. **标题前3个词必须构成完整的商品识别信息**：`[品类] + [适用人群] + [核心款式/版型]`，例如 `Рубашка мужская длинный рукав`、`Платье женское летнее`。

### 文本一致性强制检查

**目的**：确保标题中所有修饰词与被修饰名词在性、数、格上完全一致，同一概念前后不矛盾、不重复。

**逐项检查清单**：

1. **形容词与名词性数一致**：
   - `рубашка`（阴）→ `мужская рубашка`、`синяя рубашка`、`стильная рубашка`
   - `футболка`（阴）→ `женская футболка`、`белая футболка`
   - `свитшот`（阳）→ `мужской свитшот`、`серый свитшот`
   - `платье`（中）→ `летнее платье`、`черное платье`
   - `брюки`（复）→ `мужские брюки`、`черные брюки`
   - **发现不一致立即修正**，例如 `мужской рубашка` 必须改为 `мужская рубашка`。

2. **颜色词与名词一致**：
   - 同一件商品只有一个主色时，颜色词只出现一次且形式正确
   - 多色/拼色用 `в клетку`、`в полоску`、`принт`、`цветной` 等表述，禁止同时写两个矛盾颜色词
   - 禁止 `синяя рубашка синий` 这类重复且不一致的错误

3. **版型/风格前后不矛盾**：
   - 禁止同时出现 `свободный крой`（宽松）和 `облегающий`（修身）
   - 禁止同时出现 `оверсайз` 和 `приталенный`
   - 禁止同时出现 `спортивный` 和 `деловой`（除非确实是商务休闲款，用 `кэжуал` 统一）
   - 图片中是什么版型就只写对应词，不做风格叠加

4. **同一概念不重复表达**：
   - 禁止 `рубашка рубашечная`、`футболка для футбола` 这类同义反复
   - 禁止 `модный стильный` 两个近义热词连用（热词本身最多2-3个且不重复语义）
   - 禁止 `длинный рукав с длинным рукавом` 重复描述袖长

5. **名词变格在标题中统一**：
   - 标题中品类名词保持主格（именительный падеж）
   - 修饰短语中的名词按俄语语法正确变格，例如 `воротник на пуговицах`（六格复数）、`карман на груди`（六格）
   - 禁止同一短语内变格错误，例如 `воротник на пуговица` 必须改为 `воротник на пуговицах`

6. **单复数一致**：
   - `брюки`、`джинсы`、`шорты`、`легинсы` 永远用复数，修饰词也用复数
   - `рубашка`、`платье`、`футболка`、`свитшот` 用单数，修饰词也用单数
   - 禁止 `мужская брюки` 这类单复数不一致错误

### 无意义文本过滤规则

**目的**：清除标题中对买家理解商品没有任何信息增量的词汇、堆砌和中式俄语表达。

**必须删除或重写的情况**：

1. **纯热词堆砌**：
   - 禁止 `стильный модный современный удобный универсальный практичный` 连续3个以上热词
   - 热词最多2-3个，且每个热词必须与商品实际特征相关（例如家居服可以用 `удобный`，正装衬衫不宜用 `спортивный`）
   - 删除后不影响商品理解的热词一律删除

2. **无信息增量的形容词**：
   - 禁止 `хороший`、`отличный`、`замечательный`、`прекрасный`、`классный` 这类主观评价词
   - 禁止 `новый`（除非确实是新品且图片有新品标识，Ozon标题通常不需要）
   - 禁止 `обычный`、`стандартный` 这类无意义描述

3. **中式俄语直译**：
   - 禁止逐字翻译中文电商用语，例如：
     - "百搭" → 禁止写 `все подходит`，应写 `универсальный` 或直接不写
     - "显瘦" → 禁止写 `стройнит`（中式表达），应写 `приталенный`/`облегающий` 或不写
     - "高端" → 禁止写 `высокий конец`，应写 `стильный`/`элегантный` 或不写
     - "气质" → 禁止写 `темперамент`，应写 `элегантный` 或不写
   - 不确定俄语是否地道时，优先用简单、确定正确的词，不追求"高级感"而牺牲准确性

4. **语义空洞的短语**：
   - 禁止 `для любого случая`、`на все времена`、`лучший выбор` 这类空洞表述
   - 禁止 `модный тренд 2026` 这类无依据的年份趋势词（除非图片明确是当季新款且有依据）
   - 禁止 `ограниченная серия`、`эксклюзив` 这类无依据的稀缺性表述

5. **重复信息**：
   - 同一特征（颜色、袖长、领型）只描述一次
   - 品类词只出现一次（标题开头），禁止后面再重复 `рубашка`
   - 删除任何可以被其他词完全覆盖的冗余词

### 语法错误强制校验

**目的**：确保标题俄语语法100%正确，符合俄罗斯本土电商用语习惯。

**逐项校验**：

1. **名词变格正确性**：
   - 标题主名词保持主格单数（或复数，如брюки）
   - 介词短语中的名词变格正确：`с` + 工具格、`в` + 六格/四格、`на` + 六格/四格、`для` + 二格
   - 常见正确搭配：`с длинным рукавом`（工具格）、`на пуговицах`（六格复数）、`на груди`（六格）、`для повседневной носки`（二格）

2. **形容词变格正确性**：
   - 形容词与被修饰名词性数格完全一致（见"文本一致性"部分）
   - 形容词短尾形式在标题中一般不用，优先用长尾形式
   - 颜色形容词：`синий`/`синяя`/`синее`/`синие`，`белый`/`белая`/`белое`/`белые` 等

3. **词性正确**：
   - 禁止把副词当形容词用，例如 `стильно рубашка` 必须改为 `стильная рубашка`
   - 禁止把名词当形容词用，例如 `спорт рубашка` 必须改为 `спортивная рубашка`
   - 禁止动词不定式直接修饰名词，例如 `гулять рубашка` 必须改为 `рубашка для прогулок` 或删除

4. **词序符合俄语习惯**：
   - 形容词一般放在名词前：`синяя рубашка`，不是 `рубашка синяя`（后者是口语强调，标题不用）
   - 品类词放最前，修饰词在后，符合Ozon电商标题习惯
   - 短语内部词序正确：`длинный рукав` 不是 `рукав длинный`

5. **拼写正确性**：
   - 检查元音交替：`платье`（不是 `платье`）、`юбка`（不是 `юбка` 正确）
   - 检查词尾：`мужская`（不是 `мужскаяя`）、`женская`（不是 `женскаяя`）
   - 检查连字符：`темно-синий`（有连字符）、`светло-серый`（有连字符）、`оверсайз`（无连字符）
   - 检查外来词拼写：`свитшот`（不是 `свитшот` 正确）、`худи`（不变格）、`легинсы`（复数）

6. **俄语电商用语习惯**：
   - 标题用名词短语堆砌，不用完整句子，不加句号
   - 不用第一人称、第二人称（`я`、`ты`、`вы`）
   - 不用感叹号、问号
   - 商品特征用客观描述，不用命令式（`купи`、`закажи`）

### 标题质量强制校验流程（每个标题必须执行）

生成标题初稿后，**必须按顺序执行以下四轮校验**，每轮不通过则修正后重新从该轮开始：

**第一轮：命名清晰度校验**
- [ ] 标题第一个词是标准品类名词（单数主格）？
- [ ] 品类词精准对应图片实物，没有用上义词替代？
- [ ] 前3个词构成 `[品类]+[人群]+[核心款式]` 的完整识别信息？
- [ ] 买家扫一眼前3个词就能准确判断是什么商品？
- 不通过 → 重写标题开头，确保品类词精准前置。

**第二轮：文本一致性校验**
- [ ] 所有形容词与被修饰名词性数格一致？
- [ ] 颜色词形式正确且不矛盾？
- [ ] 版型/风格词前后不矛盾？
- [ ] 没有同一概念重复表达？
- [ ] 名词变格在短语内正确？
- [ ] 单复数一致（брюки类永远复数）？
- 不通过 → 修正不一致处，重新检查。

**第三轮：无意义文本过滤**
- [ ] 热词不超过2-3个且无堆砌？
- [ ] 无主观评价词（хороший/отличный等）？
- [ ] 无中式俄语直译？
- [ ] 无语义空洞短语？
- [ ] 无重复信息？
- [ ] 删除任何词后是否影响商品理解？不影响则删除。
- 不通过 → 删除无意义词或重写对应部分。

**第四轮：语法强制校验**
- [ ] 名词变格全部正确？
- [ ] 形容词变格全部正确？
- [ ] 词性使用正确（无副词当形容词等）？
- [ ] 词序符合俄语电商习惯？
- [ ] 拼写全部正确（含连字符、外来词）？
- [ ] 符合俄语电商用语习惯（名词短语、无句子、无标点错误）？
- 不通过 → 修正语法错误，重新检查。

**四轮全部通过后**，再检查字符长度（60-180）和黑名单，最终确认标题可用。

### 常见错误反面示例（必须避免）

| 错误标题 | 问题 | 修正后 |
|---|---|---|
| `одежда мужская стильная модная современная` | 品类词过于宽泛（одежда），热词堆砌，买家不知道具体是什么 | `Рубашка мужская длинный рукав темно-синяя повседневная стильная` |
| `мужской рубашка синий длинный рукав` | 形容词性不一致（мужской→мужская, синий→синяя） | `Рубашка мужская синяя с длинным рукавом` |
| `рубашка для футбола спортивная модная` | 品类错误（T恤应写футболка），中式表达 | `Футболка мужская спортивная белая повседневная` |
| `стильная модная современная удобная универсальная рубашка` | 热词堆砌（5个），品类词后置 | `Рубашка мужская свободного кроя серая повседневная универсальная` |
| `брюки мужская черный классический` | 单复数不一致（брюки是复数，应用мужские/черные/классические） | `Брюки мужские черные классические прямого кроя` |
| `платье женское для любого случая отличный выбор` | 语义空洞短语，主观评价 | `Платье женское летнее цветочное свободного кроя` |
| `свитшот мужской оверсайз облегающий` | 版型矛盾（оверсайз宽松 vs облегающий修身） | `Свитшот мужской оверсайз серый с круглым вырезом` |
| `куртка женская верхняя одежда теплая` | 重复（куртка已是上衣，无需верхняя одежда） | `Куртка женская осенняя черная свободного кроя` |

### 字符长度
60-180字符（Ozon平台推荐区间）。四轮校验通过后检查长度，过短则补充可见特征，过长则删除冗余修饰词（优先删热词，保留核心商品信息）。

### 允许使用的合规热词（每个标题最多2-3个，禁止堆砌）
стильный, удобный, универсальный, повседневный, практичный, современный, модный

热词使用原则：每个热词必须与商品实际特征相关，删除后不影响商品理解的热词一律删除。

### 黑名单（强制过滤，出现即删除或重写）
- 夸大词：лучший, супер, номер один, идеальный, топ 1, самый
- 侵权/违禁：оригинал, лицензия, любые бренды, IP-персонажи, защищенные авторским правом принты
- 促销用语：скидка, акция, распродажа, бесплатно
- 主观评价词：хороший, отличный, замечательный, прекрасный, классный
- 语义空洞短语：для любого случая, на все времена, лучший выбор, ограниченная серия, эксклюзив

### 符号约束
仅允许英文标点（逗号、句号、连字符、空格）。**禁止** `& * @ # « » № " '` 及其他特殊符号。标题末尾不加句号。

### 节日逻辑
仅当图片中**明确可见**节日装饰元素（如圣诞树、南瓜、爱心、烟花等）时，才添加对应节日词汇；无对应元素绝不添加。不可夸大。

### 语言要求
严格遵守俄语本土语法：名词变格正确、形容词与名词性数一致、搭配符合俄罗斯电商用语习惯，拒绝中式机翻俄语。生成后必须再检查一遍俄文语法及俄罗斯人用语习惯，定义准确。不确定是否地道时，优先用简单、确定正确的词，不追求"高级感"而牺牲准确性。

识别图片时，按以下维度提取信息（仅可见特征，用俄语记录）：


## 注意事项

- 用户输入的路径可能包含空格或中文，脚本调用时路径用双引号包裹。
- 图片格式支持：jpg, jpeg, png, webp, bmp。
- 文件名排序采用自然排序（01.jpg 排在 2.jpg 之前）。
- 若根目录下没有子文件夹（即根目录本身就是SKU），则将根目录本身视为唯一SKU处理。
- 若图片中人物面部完整露出，不影响内容生成，仅关注服装/商品本身。
- 标签中的俄语字母使用西里尔字母，不使用拉丁字母转写。
- **标题质量是本技能的最高优先级**：宁可标题短一些、朴素一些，也不能出现语法错误、无意义文本或让买家看不懂的品类词。四轮校验必须严格执行，不通过则重写，不得妥协。
- 不确定俄语表达是否地道时，优先使用最简单、最确定正确的词汇，避免为了"高级感"而使用不确定的表达导致语法错误。
